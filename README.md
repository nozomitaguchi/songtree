# Music Timeline

nozomitaguchiの音楽年表。1985年生まれ、ギター・バンド・ジャズ・ユニット活動から、千葉での暮らしとITエンジニアへの就職までをたどり、制作順の曲と歌詞・ライナーノーツを記録する。

**Private repository / main**。現在は実曲の目録を使ったデザイン比較用の試作。公開はしない。

## 起動

Node.js 18以降。依存パッケージ不要。

```sh
npm start
```

`http://localhost:3000`。サーバーはリモート端末からアクセスできるよう `0.0.0.0` にバインドする。実行環境のポート公開・アクセス制御は別途必要。

```sh
npm run check
```

## 試作

Gitの履歴に似たツリーで表示する。本人の音楽の歩みを幹とし、feliceとpatalpを並行する枝にする。曲はコミット風の一覧から詳細を開く。色だけでなく名前でも枝を区別する。

約2年間の並行活動と、みきちゃんの出産後のfelice終了を表示。開始・終了の正確な年、同時期の曲順、patalpの終了時期は未確認。線の長さは時間の長さを表さず、patalpを終了や合流として描かない。

経歴と曲に紐づかない「時代のノーツ」は `dist/history.json`、曲とライナーノーツは `dist/tracks.json`。曲名が分かっている12曲と、feliceのSunoリンク1件を登録済み。制作年・同時期内の曲順・各曲の作詞者には未確認項目がある。直接再生用の音源は未登録のため、曲を選んで端末内の音声ファイルを指定すると再生操作を試せる。音声ファイルはサーバーに送らない。

## 管理

- 原曲の制作時期で並べる。音源化・再制作時期とは区別する。
- 年度の仮置きは `dating: inferred`。未確認の年は `null`。年・活動内容を推測で確定しない。
- `lyricsByOwner: true` の曲だけ歌詞を表示する。それ以外はデータに歌詞を入れず、歌詞ボタンも表示しない。
- 作詞者・作曲者は分ける。共同制作の場合は、音源公開の可否も確認する。
- 本番公開で非掲載歌詞を配信データに含めない。非公開リポジトリと非公開サイトは別々に管理する。
- 実音源・歌詞・写真は許可されたものだけ追加する。
