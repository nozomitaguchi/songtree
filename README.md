# Music Timeline

nozomitaguchiの音楽年表。1985年生まれ、ギター・バンド・ジャズ・ユニット活動から、千葉での暮らしとITエンジニアへの就職までをたどり、制作順の曲と歌詞・ライナーノーツを記録する。

**Private repository / main**。現在はデザイン比較用の試作。公開はしない。

## 起動

Node.js 18以降。依存パッケージ不要。

```sh
npm start
```

`http://localhost:3000`。サーバーはリモート端末からアクセスできるよう `0.0.0.0` にバインドする。実行環境のポート公開・アクセス制御は別途必要。

```sh
npm run check
```

## 試作

画面上部で3案を切り替える。

1. レコード棚：生成り、レコードの造形、ジャケット中心のグリッド。
2. 音楽雑誌：深緑、大きな文字、アートと文章の横並び。
3. 年表：白地、余白、コンパクトな曲の一覧。

経歴と曲に紐づかない「時代のノーツ」は `dist/history.json`、曲とライナーノーツは `dist/tracks.json`。仮の3曲は実際の作品ではない。音源未登録のため、曲を選んで端末内の音声ファイルを指定すると再生操作を試せる。音声ファイルはサーバーに送らない。

## 管理

- 原曲の制作時期で並べる。音源化・再制作時期とは区別する。
- 年度の仮置きは `dating: inferred`。未確認の年は `null`。年・活動内容を推測で確定しない。
- `lyricsByOwner: true` の曲だけ歌詞を表示する。それ以外はデータに歌詞を入れず、歌詞ボタンも表示しない。
- 作詞者・作曲者は分ける。共同制作の場合は、音源公開の可否も確認する。
- 本番公開で非掲載歌詞を配信データに含めない。非公開リポジトリと非公開サイトは別々に管理する。
- 実音源・歌詞・写真は許可されたものだけ追加する。

## ファイル

- `AGENTS.md`：AIによる制作・レビューの指示
- `docs/CONTENT.md`：曲・経歴の入力手順
- `docs/DESIGN_REVIEW.md`：レビュー観点と現時点の検証範囲
- `dist/`：配信ファイル
- `scripts/`：起動とチェック
- `.openai/hosting.json`：本人のみ閲覧できるSitesプレビューの設定
