# Songtree

nozomitaguchiの曲を、枝分かれする履歴としてたどるサイト。曲が主役。曲名を常時表示し、音源・歌詞・ライナーノーツを開いて楽しむ。曲以外の節目は年の横に短い英語ラベルで表示する。詳しい背景は資料として保持する。

**Private repository / main**。曲の目録・音源・歌詞・Production notesを収録。一般公開はしない。

## 起動

Node.js 18以降。依存パッケージ不要。

```sh
npm start
```

`http://localhost:3000`。サーバーはリモート端末からアクセスできるよう `0.0.0.0` にバインドする。実行環境のポート公開・アクセス制御は別途必要。

```sh
npm run check
```

## 試作

Gitの履歴に似たツリーで表示する。本人の音楽の歩みを幹とし、feliceとpatalpを並行する枝にする。曲はコミット風の一覧から詳細を開く。明るい背景で、色だけでなく名前でも枝を区別する。曲は1曲1コミットとして常時表示し、曲以外の情報は年の横の短い英語ラベルで示す。

約2年間の並行活動を枝の並行として表示。活動終了の表示は行わず、最後の曲の記録まで線を描く。開始・終了の正確な年、同時期の曲順は未確認。線の長さは時間の長さを表さず、patalpを終了や合流として描かない。

経歴と曲に紐づかない「時代のノーツ」は `dist/history.json`、曲とライナーノーツは `dist/tracks.json`。曲名が分かっている17曲を登録済み。制作年・同時期内の曲順には未確認項目がある。全17曲のMP3を登録し、曲詳細から直接再生できる。制作順のデータは保持し、画面は新しい記録から古い記録へ並べる。

## 管理

- 原曲の制作時期で並べる。音源化・再制作時期とは区別する。
- 年度の仮置きは `dating: inferred`。未確認の年は `null`。年・活動内容を推測で確定しない。
- `lyricsByOwner: true` の曲だけ歌詞を表示する。それ以外はデータに歌詞を入れず、歌詞ボタンも表示しない。
- 作詞者・作曲者は分ける。共同制作の場合は、音源公開の可否も確認する。
- 本番公開で非掲載歌詞を配信データに含めない。非公開リポジトリと非公開サイトは別々に管理する。
- 実音源・歌詞・写真は許可されたものだけ追加する。

## ファイル

- `AGENTS.md`：AIによる制作・レビューの指示
- `docs/CONTENT.md`：曲・経歴の入力手順
- `docs/DESIGN_REVIEW.md`：レビュー観点と現時点の検証範囲
- `dist/`：配信ファイル
- `scripts/`：起動とチェック
- `.openai/hosting.json`：本人のみ閲覧できるSitesプレビューの設定

GitHubを正本とする。Sitesで修正した場合も同じソースをGitHubへ反映する。

`sources/` は取得データの私有保存。配信はdistのみ。felice以外の13曲は本人の作詞作曲と確認済み。取得した歌詞を配信する。feliceは曲名・リンク・音源のみを収録し、歌詞を掲載しない。

書体と共通枠はポートフォリオに統一（Quicksand / Zen Kaku Gothic New、同じロゴ・SNS・明るい背景・中央揃えのフッター）。スマホのヘッダーは1段。

ヘッダーはポートフォリオのアイコンとSongtree by nozomitaguchiを左揃えの1行に配置。登録音源は詳細の「再生」から直接再生し、固定プレイヤーは曲名・再生操作・閉じる操作に絞る。再生失敗は表示する。

Production notesは本人のポートフォリオにある8曲の本文を転記。原文の出典URL・GitHub blob SHAをtracks.jsonに記録し、転記前のノーツ本文をsources/production-notes.jsonに保存。未掲載曲のノーツは創作しない。

最新ヘッダーはポートフォリオのアイコンと、Songtree by nozomitaguchiを隣り合わせの1行で表示。
